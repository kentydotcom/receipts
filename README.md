# Deletion receipts

Public deletion receipts from [lookup-forget-receipt](https://github.com/kentydotcom/lookup-forget-receipt), a Fly Sprite research agent.

The agent looks up a public question, keeps notes on the Sprite, then forgets them and files a receipt here. These files record that notes were wiped. They do not contain the notes themselves.

Each receipt under `deletion/` includes:

- the paths that were removed
- a leftover hash
- a timestamp

Live demo: https://hs26-forgetful-b4at6.sprites.app
